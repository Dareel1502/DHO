# Daryl Hans Ocao — Portfolio

Personal portfolio site for Daryl Hans Ocao, Web Developer, Software Engineer & GoHighLevel (GHL) Automation Specialist.

## Features

- Responsive portfolio built with React + Vite
- AI assistant chat widget (Gemini API) that answers visitor questions about services and project fit
- Contact form, testimonials, certificates, and project showcase sections

## Tech Stack

- React + Vite
- Tailwind CSS
- Gemini API (`@google/genai`) for the AI chat assistant
- Deployed on Vercel

## Local Development

```bash
npm install
vercel dev
```

Requires a `GEMINI_API_KEY` environment variable (see `.env.local`).
